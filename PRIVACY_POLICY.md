## 1. Overview
This Privacy Policy outlines how the **Physics in Code** application interacts with Facebook services and user data. The application is an educational, developer-oriented automation tool designed solely to publish physics simulation videos (Reels) to the authorized Facebook Page **Physics in Code**.

---

## 2. Information Collected & Used
* **Facebook Graph API Permissions:** The app requests access to `pages_manage_posts`, `pages_read_engagement`, and `pages_show_list`.
* **Purpose:** These permissions are used exclusively to:
  1. Authenticate the administrator to the designated Facebook Page.
  2. Upload and publish educational physics Reels, captions, and thumbnails.
* **No Third-Party User Data Collection:** The application does **not** collect, scrape, store, or sell any personal data from visitors, followers, or third-party Facebook users.
* **Credentials Storage:** All access tokens and configuration settings are stored locally and securely on the developer's personal machine and are never transmitted to external third-party servers.

---

## 3. Data Sharing & Third-Party Disclosure
* We do **not** sell, trade, or share any information with third parties.
* Content is transmitted directly between the local publishing client and Meta's official Graph API endpoints (`graph.facebook.com` and `rupload.facebook.com`).

---

## 4. User Data Deletion Instructions
If you wish to revoke access or remove all data associated with this application, you can do so at any time:

1. Log in to your Facebook account.
2. Go to **Settings & Privacy** ➔ **Settings**.
3. In the left menu, select **Security and Login** ➔ **Business Integrations** (or **Apps and Websites**).
4. Find **Physics in Code**.
5. Click **Remove** to revoke all permissions and delete the token association.

Alternatively, you can open an issue or request data removal at:  
👉 [https://github.com/GeoSId/SimplePhysics/issues](https://github.com/GeoSId/SimplePhysics/issues)
